## 🔍 Scope of the Project

RuleSetRAT is a malware analysis and detection project. It contains:

- Static YARA rules targeting specific RAT variants and builder generations
- Output data from static tools such as CAPA and Detect It Easy
- File hashes and structural metadata

❗ This project does NOT contain:

- Live, executable, or decrypted malware binaries
- Scripts that deliver or exploit malicious code
- Any form of malware distribution

All analysis is performed in isolated virtualized environments using inert or encrypted samples. Files are structured for static study and rule validation only.
