# 📚 Project Philosophy

RuleSetRAT is not just a collection of malware signatures — it is a structured attempt to catalog, fingerprint, and statically detect historically significant but under-documented RAT builders.

## 🧠 Why Variant-Specific Rules?

- Generic family-level rules result in high false positives
- Builders often mutate byte structure, entropy, and imports per version
- Precise fingerprinting enables accurate threat attribution

## ⚔️ Accuracy over Coverage

We chose to trade mass coverage for forensic reliability:

- If a rule exists here, it is highly likely to detect exactly one known variant
- This allows threat hunters and analysts to trace sample lineage confidently

## 📏 High Standards

- Each rule is hand-crafted using behavioral and structural analysis
- No rules are autogenerated or mass-generated
- Metadata is as important as detection capability

RuleSetRAT is designed as a tool for professionals, researchers, and advanced students who value signal over noise.
